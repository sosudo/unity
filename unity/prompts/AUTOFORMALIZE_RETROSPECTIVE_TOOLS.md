# Available tools for `unity autoformalize` — retrospective

Start with `autoformalize_brief(author)` and `autoformalize_metrics()` for compact accepted state and run telemetry.
Use `autoformalize_status()` for exact candidate identities, `artifact_info` and bounded `artifact_read` for
specific verification/source evidence, and `forum_read` for relevant discussion only when needed.

The task supplies the exact library directory, report path, run ID and JSON schema. Save reusable
evidence-backed lessons there and record their paths in the requested retrospective report, or record
`no_changes` with a concrete reason. Do not edit supplied sources or accepted Lean, reopen the pipeline,
read full transcripts by default, or treat an unsaved chat summary as a completed retrospective.
